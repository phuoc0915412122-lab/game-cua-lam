# Hướng dẫn đóng góp

Chào mừng bạn đóng góp cho Vua Bóng Tối — Pixel Arena.

## Quy trình đề xuất

1. Mở issue để mô tả lỗi, ý tưởng hoặc thay đổi lớn.
2. Fork repository hoặc tạo branch mới, ví dụ `feature/new-animation` hay `fix/input-bug`.
3. Chỉ sửa phần liên quan; giữ nguyên kích thước và nền trong suốt của sprite theo quy ước trong `VUA_BONG_TOI_GRAPHICS_README.txt`.
4. Kiểm tra game và viewer bằng trình duyệt trước khi gửi.
5. Tạo Pull Request, mô tả lý do, thay đổi và cách kiểm tra. Với đồ họa, đính kèm ảnh trước/sau nếu có.

## Lưu ý

- Không commit mật khẩu, token, khóa API hoặc dữ liệu cá nhân.
- Không thêm thư viện/binary lớn nếu chưa giải thích lý do.
- Tôn trọng quyền sử dụng của mã và hình ảnh bên thứ ba; ghi nguồn khi cần.
- Thảo luận trong issue trước khi thay đổi định dạng asset hoặc điều khiển game.
